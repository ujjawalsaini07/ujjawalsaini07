## Projects

**[SmartHire](https://github.com/ujjawalsaini07/SmartHire)** — Role-based job portal for job seekers, recruiters, and admins: posting, search/filtering, application tracking, and recruiter analytics. React + Vite frontend, Node/Express + MongoDB backend. [Live](https://smarthire-project-ujjawalsaini.vercel.app/)

**[open_router](https://github.com/ujjawalsaini07/open_router)** — Multi-service backend (Turborepo workspaces: `api-backend`, `primary-backend`, shared `db`) exploring an OpenRouter-style API gateway pattern. Express + Prisma/Postgres, JWT auth, Zod validation, TypeScript throughout.

**[Resume_builder](https://github.com/ujjawalsaini07/Resume_builder)** — AI-assisted resume builder: guided section editor, multiple templates, PDF upload with AI parsing (Gemini) into structured data, public share links. React + Vite frontend, Express + MongoDB backend. [Live](https://resume-builder-ten-plum.vercel.app)

**[MarketCamp](https://github.com/ujjawalsaini07/MarketCamp)** — Email marketing SaaS MVP: campaign builder, audience/contact management, tracking and analytics, mock Stripe checkout. Next.js frontend, Express + Prisma backend, standalone SMTP relay service. [Live](https://market-camp.vercel.app)
